SLIDE 2 — PROJECT OVERVIEW
───────────────────────────
Title: What is SkyTrip?
Bullet Points:
  - A mobile flight booking application inspired by Royal Jordanian Airlines
  - Cross-platform: runs on Android, iOS, Web, and Desktop from a single Flutter codebase
  - Connected to a live REST API hosted on Microsoft Azure
  - Supports the full booking lifecycle: search, book, pay, and receive a boarding pass
  - Three user roles: Client (mobile app), Employee (web dashboard), Admin (web dashboard)
  - Bilingual: supports English and Arabic with full RTL layout


SLIDE 3 — SYSTEM ARCHITECTURE
──────────────────────────────
Title: System Architecture
Diagram description (draw a simple 3-layer diagram):

  [Flutter Mobile App]  ←→  [ASP.NET Core REST API (Azure)]  ←→  [SQL Server Database]
         ↕                            ↕
  [Flutter Web Dashboards]     [Stripe Payment Gateway]
                                      ↕
                               [Email Service]

Key Points:
  - Frontend: Flutter with Provider state management
  - Backend: ASP.NET Core Web API hosted on Azure App Service
  - Database: SQL Server with Entity Framework Core
  - Payments: Stripe Checkout integration
  - Email: Automated booking confirmation and cancellation emails


SLIDE 4 — KEY FEATURES (CLIENT APP)
────────────────────────────────────
Title: Client App Features
Bullet Points:
  - User Registration with Email Verification (6-digit OTP)
  - Flight Search: One-way, Round-trip, and Multi-city
  - Full Booking Flow: search → select flight → add passengers (with passport/ID upload) → choose services → select seat → pay via Stripe
  - Digital Boarding Pass with QR Code
  - Multi-currency Support: JOD, USD, EUR, GBP, AED with live conversion
  - Dark Mode and Light Mode themes

SLIDE 6 — BOOKING FLOW
───────────────────────
Title: Booking Flow (Step by Step)
Show as a horizontal flow diagram with arrows:

  Search Flights → Select Flight → Confirm & Create Booking → Add Passengers (with document upload) → Select Extra Services → Select Seat → Pay via Stripe → Receive Boarding Pass with QR Code

Key Technical Points:
  - Each step creates records on the backend via API calls
  - Passenger documents (passport/ID photos) uploaded as multipart form data
  - Payment handled via Stripe Checkout Sessions with deep-link callbacks
  - Payment status polled every 1.5 seconds until confirmed

SLIDE 10 — CHALLENGES & SOLUTIONS
──────────────────────────────────
Title: Challenges We Faced

  Challenge 1: Multi-city flight search
    - Problem: Backend returns a flat list of segments, not grouped by legs
    - Solution: Frontend groups flights by departure/arrival to match each leg

  Challenge 2: Payment integration on mobile
    - Problem: Stripe doesn't have a native Flutter SDK
    - Solution: Used Stripe Checkout Sessions via API + Chrome Custom Tabs + deep link callbacks for payment status

  Challenge 3: Cross-platform consistency
    - Problem: Maintaining consistent UI across Android, iOS, and Web
    - Solution: Flutter's single codebase with adaptive theme system (light/dark mode, RTL support)
